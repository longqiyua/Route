# Route 重做设计（2026-07-28）

## 目标
治"打开莫名其妙"：做好引导；按模式重组信息架构；统一视觉（logo 强调色 + 黑白灰 + 深浅模式）。

## 产品架构
- **2 大模式**
  - **基础模式**（默认，现在做）：自动追踪选定文件 + 修改表 + 回退。独特功能，需绝对性能/稳定。
  - **AI 协同模式**（标 BETA，现在不做）：现有非基础功能（手动 commit / 分支 / diff / 全周期回退 / 历史 / 标签 / 同步 / 统计 / 插件）全部收纳于此。
- **备份**：端点模式（默认），目的地 **二选一**：本地 / 云（无第三选项）。
- **存储类型**：镜像（纯复制、无版本）/ 辅存（走 Route 仓库、diff + 全周期回退）。
- **统计增强**：用户文件总大小 + 修改次数 + 修改类型识别（文本 / 代码 / 其他，多类型）。
- **route A 标签**：扫描文件内 `route A` 注释 → 自动创建统计分类；需自动读用户文件；**默认关闭**；开启时提示"软件会读取用户文件"。

## 视觉系统
- **Logo**：勒洛三角形（带圆孔、evenodd）+ "route" wordmark，Poppins 600；图标色 `#B4AEEA`。
- **配色**：唯一强调色 `#B4AEEA` + 黑白灰阶。深色 `#0A0A0B` 底 / `#F5EFE6` 字；浅色 `#F8F8F8` 底 / `#0A0A0B` 字。
- **字体**：wordmark = Poppins；UI = Hanken Grotesk；等宽 = JetBrains Mono。
- **深浅模式**：右上角切换，实时生效，持久化。
- **自定义标题栏**：`decorations:false`；左 [logo][自定义菜单]；右 [深浅切换][开关按钮][窗口最小/最大/关闭]；可拖拽。

## 现状映射（复用，避免重写后端）
辅存=route-basic 仓库；镜像=sync mirror；端点本地=sync local+调度；云=sync webdav/s3/relay/server。基础模式自动追踪=新功能（P2）。
